Confidentialité

Mise à jour : 8 novembre 2026

Quiera fonctionne sur votre PC. Pas de compte, pas de publicité, pas de télémétrie : aucune statistique d'utilisation n'est envoyée, et rien ne passe par un serveur de Quiera.

Ce qui passe par Internet

  • Les paroles synchronisées. Pour trouver les paroles du morceau en cours, Quiera envoie son titre, son artiste, son album et sa durée à LRCLIB, une base de paroles ouverte. Les paroles mot à mot de NetEase sont une option, désactivée par défaut ; activée, la même recherche part aussi vers NetEase. Pour couper : Réglages › Musique › Paroles synchronisées.
  • Les mises à jour. Au démarrage, puis toutes les 6 heures, Quiera lit la liste des versions publiées sur GitHub. Aucune donnée personnelle n'est envoyée ; comme pour toute page web, GitHub voit l'adresse IP de la requête (politique de GitHub). Pour couper : Réglages › À propos › Rechercher automatiquement.
  • Votre agenda, si vous l'ajoutez. Quand vous collez le lien iCal d'un agenda (Google, Outlook, iCloud…), Quiera le télécharge directement à cette adresse, puis tous les quarts d'heure. Le lien reste sur votre PC, dans les réglages, et n'est jamais écrit dans le journal ; les événements sont gardés en mémoire. Pour couper : Réglages › Agenda, retirez le lien.
  • Ce que vous demandez. Une recherche web lancée depuis le lanceur s'ouvre dans votre navigateur ; un lien d'une notification ou d'un agent aussi.

Ce qui reste sur votre PC

  • Les notifications et l'historique du presse-papiers : gardés en mémoire seulement, effacés à la fermeture de Quiera.
  • Le Shelf : les chemins de vos fichiers (jamais copiés), enregistrés seulement si vous gardez le Shelf entre deux sessions.
  • L'index des fichiers du lanceur : les noms des fichiers, en mémoire.
  • Le miroir : l'image de la webcam s'affiche dans l'île seulement pendant que l'onglet est ouvert. Elle n'est ni enregistrée ni envoyée.
  • Les batteries des appareils Bluetooth : lues auprès de Windows, affichées, jamais envoyées.
  • Les réglages, dans le dossier de Quiera (%APPDATA%\app.quiera).
  • Le journal (%LOCALAPPDATA%\app.quiera\logs) : des événements techniques, jamais le titre d'un morceau, le contenu d'une notification, de ce que vous copiez ou de ce que font vos agents IA.

Les agents IA (Claude Code, Codex)

Ces fonctions sont désactivées tant que vous ne les activez pas dans Réglages › Agents IA.

  • Configuration. Quiera ajoute des « hooks » à ~/.claude/settings.json ou ~/.codex/hooks.json, après une copie de sauvegarde (.quiera-backup), et une ligne d'état à Claude Code si vous n'en avez pas. Les désactiver retire ces ajouts sans toucher à vos réglages.
  • Ce que l'île reçoit. À chaque étape, l'agent transmet à Quiera, sur votre PC seulement : le dossier du projet, l'outil utilisé, le fichier, la page ou la commande concernés, et, pour une demande, le code modifié, le plan ou la question. Jamais vos messages à l'agent. Ces informations restent en mémoire, s'affichent dans l'île et disparaissent à la fermeture.
  • Quotas. Les pourcentages d'utilisation sont lus dans la ligne d'état de Claude Code et dans les fichiers de session de Codex (~/.codex/sessions), dont Quiera ne garde que les chiffres. Les derniers sont enregistrés dans agents-usage.json, dans le dossier de Quiera.
  • Le téléphone. Si vous affichez le QR code, une page est servie par votre PC sur votre réseau local, à une adresse secrète valable 8 heures : elle montre les demandes en cours. Rien ne passe par Internet. « Délier le téléphone » la coupe.
  • Claude Code et Codex échangent eux-mêmes avec Anthropic et OpenAI, selon leurs propres règles ; Quiera n'y ajoute rien.

Envoyer au téléphone

Quand vous le demandez, les fichiers passent directement du PC au téléphone par votre réseau local, à un lien qui ne marche que 10 minutes. Rien ne passe par Internet ni par un serveur de Quiera.

Le site quiera.eu

Le site est hébergé par Vercel, qui traite les adresses IP des visiteurs pour servir les pages et les protéger. Les visites sont comptées par Vercel Web Analytics, sans cookie : seules des statistiques globales (pages vues, pays, navigateur) sont gardées, sans rien qui permette de vous reconnaître d'un jour à l'autre. Le site ne dépose aucun cookie ; seul votre choix de thème est retenu, dans votre navigateur.

Vos droits

L'éditeur ne détient aucune donnée personnelle vous concernant. Pour une question, ouvrez une issue sur GitHub. Vous pouvez aussi adresser une réclamation à la CNIL.
