Release and signing policy

Quiera's Windows installer is not signed with a code-signing certificate yet, so Windows SmartScreen may warn about it the first time. Here is how each release is built, and how you can check what you install.

How releases are built

The Windows installer of each Quiera release (Quiera-Setup-x64.exe) is published on GitHub Releases. Every installer is built by GitHub Actions from the tagged commit of the public repository, quierapro/quiera-island. Nothing built elsewhere is published.

How to check what you install

  • Checksum: each release carries Quiera-Setup-x64.exe.sha256, the SHA-256 of its installer. In PowerShell, Get-FileHash Quiera-Setup-x64.exe must print the same value.
  • Updates: the update packages Quiera installs by itself are signed with the project's update key, and the app checks that signature before installing anything.
  • winget: the manifest submitted to Microsoft's catalogue pins the installer's SHA-256, and winget refuses a file that doesn't match.

If Quiera is ever signed with a code-signing certificate, this page will name its provider.

Team roles

  • Committers and reviewers: quierapro. Changes from other people come as pull requests, and each one is reviewed by a committer before it is merged.
  • Approvers: quierapro.

All team members use multi-factor authentication on GitHub.

Privacy

Quiera has no account, no advertising and no telemetry. It sends information over the network only for the features below; each one can be turned off in its settings, and the installer shows this notice. The full policy is on the privacy page.

  • Synced lyrics: the playing track's title, artist, album and duration go to LRCLIB to find its lyrics (Settings › Music). Word-by-word lyrics from NetEase are off by default.
  • Updates: Quiera reads the list of releases on GitHub at start and every six hours; no personal data is sent (Settings › About). GitHub's privacy statement applies to that request.
  • Calendar: only if the user pastes a calendar's iCal link, Quiera downloads it from that address every 15 minutes. The link stays on the PC and is never written in the logs (Settings › Calendar).
  • Send to a phone: when the user asks, files go straight from the PC to the phone over the local network, never through the Internet.

Uninstalling

Quiera uninstalls like any app: Windows Settings › Apps › Installed apps › Quiera › Uninstall.
