Le nuage violet de Quiera, partout. *Quiera's purple cloud, everywhere.*

## Installer

Si Quiera est installée, elle propose cette mise à jour toute seule : icône Quiera › **Installer la mise à jour 0.1.5**, ou Réglages › À propos. Sinon, téléchargez **Quiera-Setup-x64.exe** ci-dessous et lancez-le ; vos réglages restent. Windows peut afficher « Windows a protégé votre ordinateur » : **Informations complémentaires**, puis **Exécuter quand même** (l'installateur n'est pas encore signé par un certificat).

## Corrigé

- Le logo de Quiera est le nuage violet du site : dans Réglages › À propos, l'icône près de l'horloge, la barre des tâches, la recherche Windows et l'installateur.

## English

Quiera's icon is now the purple cloud of quiera.eu: in Settings › About, the notification area, the taskbar, Windows search and the installer.
