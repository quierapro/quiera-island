Quiera parle anglais. *Quiera now speaks English.*

## Installer

Si Quiera 0.1.1 est installée, elle propose cette mise à jour toute seule : icône Quiera › **Installer la mise à jour 0.1.2**, ou Réglages › À propos. Sinon, téléchargez **Quiera-Setup-x64.exe** ci-dessous et lancez-le ; vos réglages restent. Windows peut afficher « Windows a protégé votre ordinateur » : **Informations complémentaires**, puis **Exécuter quand même** (l'installateur n'est pas encore signé par un certificat).

## Nouveau

- **Interface en anglais** : l'île, les Réglages, l'accueil, le menu de l'icône et l'installateur sont en français ou en anglais. Quiera suit la langue d'affichage de Windows ; Réglages › Général › Langue permet d'en choisir une.
- **La page d'envoi vers le téléphone** s'affiche dans la langue du téléphone.

## English

Quiera now follows Windows' display language: French, or English for every other language. To choose, open Settings › General › Language. If Quiera 0.1.1 is installed, it offers this update itself (Quiera icon › **Install update 0.1.2**).
