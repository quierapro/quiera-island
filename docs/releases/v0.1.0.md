Première version publique de Quiera, la Dynamic Island native pour Windows.

## Installer

1. Téléchargez **Quiera-Setup-x64.exe** ci-dessous et lancez-le.
2. Windows peut afficher « Windows a protégé votre ordinateur » : l'installateur n'est pas encore signé par un certificat. Cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. L'île apparaît en haut de l'écran. Les réglages s'ouvrent depuis l'icône de Quiera dans la barre des tâches.

L'installateur est compilé par GitHub Actions à partir du code de cette version. Son empreinte SHA-256 est dans `Quiera-Setup-x64.exe.sha256`.

## Ce que fait l'île

- **Musique** : toute appli qui annonce sa lecture à Windows (Spotify, Deezer, YouTube dans le navigateur…), avec pochette, progression, aléatoire et répétition.
- **Paroles synchronisées**, mot à mot dans la pilule, ligne par ligne dans le lecteur (LRCLIB).
- **Lanceur** (Alt+Espace, modifiable) : applis, fichiers de tous vos disques, calculs, recherche web ; « images », « vidéos », « musique », « documents » filtrent par type.
- **Notifications** de Windows sur l'île ; un clic ouvre l'appli. Le mode Ne pas déranger est respecté.
- **Contrôles rapides** : Wi-Fi, Bluetooth, volume, sortie audio, volume par application.
- **Shelf** pour garder des fichiers sous la main, et **historique du presse-papiers** (en mémoire seulement).
- **Aperçus** : chargeur, casque et sa batterie, Verr. Maj, volume.
- **Réglages** : démarrage avec Windows, écran, ouverture au survol, plein écran, raccourci du lanceur ; lanceur, notifications, presse-papiers, paroles et aperçus activables un par un.

## À savoir

- Testé sur Windows 11. Windows 10 devrait fonctionner, sans garantie pour l'instant.
- Linux et macOS ne sont pas encore pris en charge.
- Pour voir les notifications, Windows demande d'autoriser Quiera à les lire.
- Rien n'est envoyé sur Internet, sauf la recherche des paroles (titre, artiste, album, durée).

Un problème ? [Ouvrez une issue](https://github.com/quierapro/quiera-island/issues).
